# Corrections policy

If something on The War On News is wrong, we want to fix it, and we want the fix to be visible.

## How to report an error

Email corrections@thewaronnews.com with the address of the page, the statement you believe is wrong and what the record shows instead, with a link to a source if you have one. Software agents can file the same request through the suggest_correction tool on our public MCP server at /mcp. Tips about incidents we have not recorded go to tips@thewaronnews.com.

## What happens next

We acknowledge every correction request within 48 hours. We then check the statement against its source and against what you sent.

If the entry is wrong, we publish a new claim that supersedes the old one and add a dated correction note to the entry saying what changed and when. The earlier version stays available in the entry's history. Nothing is rewritten silently. Every correction also appears in our public log at [/corrections/log](/corrections/log), with the date, the page and what changed. If we conclude that no correction is needed, we reply with our reasons.

## Corrections and updates

A correction means the entry was wrong when we published it: a wrong date, name, office, quotation, figure, source or status. An update means events moved on: a court ruled, a credential was restored, an official issued a new statement. An update changes the status line and the "updated" date and keeps the earlier status in the entry's history. It does not carry a correction note, because nothing was wrong.

## Disputes about wording

Some requests are about how an action is described rather than whether it happened: that a restriction was not a ban, or that a justification was left out. We resolve these toward the sourced record. An entry uses the verb its primary document or source uses, and it quotes the stated justification verbatim. If an official, an office or an outlet has published a statement we have not included, send it to us. If it meets our inclusion rules, we add it, quoted and dated. We do not change a description the record supports because a party would prefer a different one.
