## Each brief's contents

Every `<slug>.json` file in this folder contains, per document:
- `keyword` (and `note_on_keyword` where the accepted Surfer phrase differs from the literal request)
- `surfer_document_url`
- Market / language / device / content type / writing mode
- `content_structure`: recommended word count, headings, paragraphs, and images ranges
- `terms_to_use`: the full list of SEO terms Surfer flagged as "included" (81 per document, Surfer's cap), each with its recommended min/max occurrence count
- `terms_meta`: totals for all/included/NLP/ignored terms
- `questions_people_also_ask`: the People-Also-Ask questions Surfer surfaced
- `topics_and_questions_competitor_sourced(_sample)`: competitor-sourced topic/heading ideas
- `ai_search_info_to_cover`: the AI Search fact clusters Surfer recommends covering (with individual facts)
- `top_competitors`: the ranking competitor pages (title, URL, SEO score, word count, and authority where shown)
- `topic_clusters`: note that Surfer's Content Editor does not expose a separate topic-cluster map for this document type (that lives in Topic Research, run separately — see research-keywords.md section 2)
- `source_research_row`: pointer back to the relevant row/section in `research-keywords.md`
