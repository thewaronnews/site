# Corrections

If something on The War On News is wrong, we correct it in public.

## How to report an error

Email corrections@thewaronnews.com with the address of the page, the statement you believe is wrong and what the record should say instead, with a source link if you have one. Software can file the same request through the suggest_correction tool on the site's MCP endpoint at [/mcp](/mcp). Tips about incidents not yet recorded go to tips@thewaronnews.com.

## What happens next

We acknowledge every correction request within 48 hours, then check the statement against its source and against what you sent. If we conclude that no correction is needed, we reply with our reasons.

## How a correction appears

The corrected statement supersedes the old one, and a dated note on the entry says what changed and when. The earlier text stays visible in the entry's history. Nothing is changed silently. Every correction is also listed in the public log at [/corrections/log](/corrections/log), with the date, the page and what changed.

## Corrections and updates

A correction means an entry was wrong when it was published: a wrong date, name, office, quotation, figure, source or status. An update means events moved on: a court ruled, a credential was restored or an official made a new statement. An update changes the status line and the "updated" date and keeps the earlier status in the entry's history. It carries no correction note, because nothing was wrong.

## Disputes about wording

Some requests concern how an action is described rather than whether it happened. We resolve these toward the sourced record: an entry uses its source's verb and quotes the stated justification verbatim. If a published statement is missing from an entry, send it to us; if it meets the site's standards, we add it, quoted and dated.
